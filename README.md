# NSB Score Sheet

Built files for https://baodongxliu.github.io/nsb-score-sheet/, scorekeeping for National Science
Bowl practice matches, for coaches who keep score without seeing the questions. This repository is
generated by a deploy script; edit the source, not these files.

The app contains no student data, no questions and no answers, and loads none: coaches make their
teams on their own devices, where the names stay.
